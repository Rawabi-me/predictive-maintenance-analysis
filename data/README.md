# Data

- **Source:** AI4I 2020 Predictive Maintenance Dataset, UCI Machine Learning Repository: https://archive.ics.uci.edu/dataset/601/ai4i+2020+predictive+maintenance+dataset
- **License:** Creative Commons Attribution 4.0 International (CC BY 4.0). Credit is required when using the data.
- **Citation:** AI4I 2020 Predictive Maintenance Dataset (2020). UCI Machine Learning Repository. https://doi.org/10.24432/C5HS5C
- **Nature:** synthetic dataset (simulated industrial data), not real operational data.

## How to get the data
1. Download the dataset from the URL above.
2. Place the CSV file in this folder, named `ai4i2020.csv` (rename if needed).

The CSV is excluded from version control via `.gitignore`.
